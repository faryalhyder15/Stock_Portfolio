# 📈 Stock Portfolio Tracker

A simple and interactive **command-line Python application** that allows users to manage and track their stock investments.
---

## 🚀 Features

* 📊 View available stocks with current prices
* ➕ Add multiple stocks with quantities
* 🔁 Update existing stock quantities dynamically
* 💰 Calculate total investment value
* 📄 Display a well-formatted portfolio summary
* 💾 Save results as:

  * CSV file
  * TXT report
  * Or both

---

## 🛠️ Technologies Used

* Python
* Built-in libraries:

  * `csv`
  * `os`
  * `datetime`

---

## 📂 Project Structure

```
Stock_Portfolio.py   # Main application file
```

---

## ▶️ How to Run

1. Make sure Python is installed on your system.
2. Download or clone this project.
3. Open terminal/command prompt.
4. Run the script:

```bash
python Stock_Portfolio.py
```

---

## 🧑‍💻 How It Works

1. The program displays a list of predefined stocks with prices.
2. User inputs stock ticker symbols and quantities.
3. The system calculates:

   * Individual stock value
   * Total portfolio value
4. A summary is displayed in a clean tabular format.
5. User can choose to save results in CSV or TXT format.
